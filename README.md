# Eritroteste [PT-BR]
ERITROTESTE é um aplicativo baseado em redes neurais artificias para o diagnóstico autônomo de anemias. Ele utiliza redes neurais artificiais já treinadas e exames de Eritrograma informados pelo usuário para determinar a probabilidade de este ter anemia. Em casos positivos, o programa ainda classifica quanto a morfologia e cromaticidade.

Os arquivos iniciados em app controlam o funcionamento do programa. app_teste é o arquivo principal. Os arquivos app_dialogbox_resultado e app_dialogbox_apenas_anemia são responsáveis pelas caixas de diálogo com os resultados para anemia e suas classificações ou resultado negativo de anemia.
Os arquivos iniciados em rede são a redes neurais artificiais treinadas.

## ERITROTESTE TUI 

ERITROTESTE TUI é a versão mais leve e rápida do aplicativo ERITROTESTE. Essa versão também permite o teste de milhares de exames simultaneamente (vide vídeo).

O arquivo "menu_inicial" é o arquivo principal e o que deve ser executado. Todos os outros arquivos estão amarrados nas opções do menu inicial e são chamados conforme execução e interação do usuário. É necessário aplicativos que executem a extensão .xls estejam instalados.

# Eritroteste [EN]
ERITROTESTE is an application based on artificial neural networks for the autonomous diagnosis of anemia. It uses pre‑trained artificial neural networks and user‑provided erythrogram test results to determine the probability of anemia. In positive cases, the program also classifies the anemia according to morphology and chromaticity.

Files beginning with app control the program’s operation. app_teste is the main file. The files app_dialogbox_resultado and app_dialogbox_apenas_anemia are responsible for the dialog boxes that display the results for anemia and its classifications, or a negative anemia result.
Files beginning with rede are the trained artificial neural networks.

## ERITROTESTE TUI
ERITROTESTE TUI is the lighter and faster version of the ERITROTESTE application. This version also allows testing thousands of exams simultaneously (see video).

The file menu_inicial is the main file and the one that must be executed. All other files are linked to the options in the initial menu and are called according to user interaction and execution flow. Applications capable of opening .xls files must be installed.
